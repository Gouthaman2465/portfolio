Aegis-Web: Multi-Role Access-Control Testing Platform

FastAPI · PostgreSQL 16 · React 19 SPA · TypeScript 5.x · Playwright Chromium · Async Worker Queue

A public, enterprise-grade automated security assessment platform engineered specifically to detect and verify OWASP A01:2021 (Broken Access Control) in modern web applications and APIs. Conventional DAST scanners routinely miss access control flaws because they evaluate requests in isolation without tenant or privilege context. Aegis-Web solves this by recording genuine authenticated user sessions using Playwright Chromium across distinct roles, normalizing dynamic responses, and executing automated cross-role differential replays with mathematically grounded similarity scoring and strict false-positive suppression.

  • Headless Playwright Chromium Crawler: Authenticates across multi-tier accounts (Admin, Auditor, Standard User) and records authentic DOM routes and state-mutating API calls.
  • Cross-Role Differential Replay Engine: Executes automated cross-role replays across privilege boundaries to flag Horizontal IDOR, Vertical Privilege Escalation, and Unauthenticated Access with normalized response body comparisons.
  • Queue Architecture: High-performance FastAPI backend enqueues jobs to PostgreSQL 16 using FOR UPDATE SKIP LOCKED with an async background worker runner.
  • React 19 DiffViewer Dashboard: Full single-page application presenting visual diffs, Levenshtein & sequence similarity scoring, and false-positive suppression controls.

GraphQL AST · Zero-Trust Architecture · Python · Ownership Enforcement

An in-line security proxy that blocks Broken Object Level Authorization (BOLA) at the schema level before queries reach downstream resolvers. Eliminates reliance on individual developers remembering to implement authorization checks inside nested resolvers.
